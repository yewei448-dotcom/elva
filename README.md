# 锦官行旅｜成都旅行工作室独立站

一个无构建依赖的静态独立站，用于展示成都旅行工作室的三条主题路线、旅游服务、真实照片路线地图与预约咨询功能。

## 页面内容

- 古风视觉：首页卷轴、宣纸底纹、朱砂印章、墨色山水氛围
- 三条成都路线：古蜀人文线、烟火美食线、山水熊猫线
- 真实照片地图：用 Wikimedia Commons 真实照片作为地图节点
- 旅游服务：路线策划、本地向导、古风旅拍、用车、亲子研学、预约代订
- 功能交互：移动端导航、路线切换、服务筛选、照片地图提示、图片预览、FAQ、预约表单校验

## 本地预览

直接打开 `index.html`，或在仓库目录启动本地服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 文件结构

```text
index.html   # 页面结构与中文内容
styles.css   # 古风视觉、响应式布局
script.js    # 页面交互与表单校验
```
